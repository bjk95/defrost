Task-oriented walkthroughs. Start with the Quickstart, then pick the
guide that matches what you're trying to do.

- **[Quickstart](./quickstart/)** — install defrost, record your
  first run, see the result.
- **[Recording test results](./recording-tests/)** — wire defrost
  into pytest, Jest, Vitest, or `go test`.
- **[Recording evals](./recording-evals/)** — push eval metrics from
  any language via OpenTelemetry.
- **[Suppressing known-failing tests](./suppressing-tests/)** — keep
  CI green without skipping in source.
- **[Running the dashboard](./dashboard/)** — `defrost serve` and
  what you can do with it.
- **[CI setup](./ci-setup/)** — recording runs from GitHub Actions.

If you need exact behaviour rather than walkthroughs, see the
[reference](../reference/).
